## ✨ Features

### 📊 Core Features
- **Weekly Roster View** — Papar task minggu semasa (Isnin → Ahad)
- **Auto-detect Minggu** — Auto update bila minggu bertukar
- **Multiple Task Types** — Office, WFH, AL, MC, Outstation
- **Color-coded Cells** — Setiap jenis task ada warna sendiri
- **Highlight Hari Ini** — Kolum hari ni di-highlight khas
- **Weekend Auto-highlight** — Sabtu & Ahad kuning automatik

### 🎯 Editing & Interaction
- **Click to Edit** — Klik mana-mana sel untuk edit
- **Auto-Merge** — Sel berturut-turut dengan task sama akan merge
- **Bulk Edit** — Ctrl+Click pilih multiple sel → edit sekali gus
- **Copy-Paste** — Ctrl+C / Ctrl+V untuk copy task
- **Drag Duplicate** — Duplicate task ke sel sebelah
- **Right-click Menu** — Context menu untuk copy, paste, clear

### 🎨 Data Management
- **Copy Minggu Lepas** — Copy semua task minggu lepas ke minggu ni
- **Auto-Archive** — Data > 4 minggu auto pindah ke archive
- **Trash System** — Data yang dipadam masuk Trash, boleh restore dalam 30 hari
- **Search Tester** — Cari tester ikut nama
- **Screenshot Mode** — Export table sebagai PNG

### 📈 Analytics
- **Bar Chart** — Jenis task minggu ni
- **Doughnut Chart** — Distribution task
- **Line Chart** — Trend 4 minggu

### 👥 Collaboration
- **Realtime Presence** — Nampak siapa tengah online
- **Live Cursor** — Nampak siapa tengah edit sel mana
- **Multi-user Sync** — Data sync realtime via Firebase

### 🛠️ Testing & Utils
- **Responsive** — Boleh guna di phone & desktop
- **Dark Mode Ready** — (akan datang)
